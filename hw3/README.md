# ИДЗ-3. Гостиница на взаимодействующих процессах

Нужен Linux: безымянные семафоры, `sem_timedwait` и `prctl` на macOS не работают

| Программа | Оценка | Устройство |
|---|---|---|
| `hotel_named` | 4-5 | родитель через `fork` запускает администратора и клиентов, именованные семафоры + разделяемая память |
| `hotel_unnamed` | 6 | то же, безымянные семафоры в разделяемой памяти |
| `hotel_admin` + `hotel_client` | 7-8 | независимые программы, именованные семафоры + разделяемая память |

```bash
make
./hotel_named -r 3 -n 12 -q 5 -x 42
./hotel_unnamed -c tests/basic.conf -l run.log

./hotel_admin -r 2 -d 20      # в одном терминале
./hotel_client -s 2-4          # в других, сколько угодно раз

make test
```
