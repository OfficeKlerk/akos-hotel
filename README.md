# Задача 12. Гостиница

Последовательная (дискретно-событийная) имитация на C, только libc и системные вызовы.

```bash
make && ./hotel --help
./hotel -r 3 -n 12 -q 5 -x 42
./hotel -c tests/basic.conf -l run.log
make test
```

Администратор и клиенты - отдельные сущности (типы данных и функции), которые
взаимодействуют через события, обрабатываемые в порядке модельного времени

Особенности:
1) освободившийся номер получает очередь, а не вновь прибывший клиент
2) срок проживания всегда отрабатывается полностью, даже при остановке
3) Ctrl+C: первое нажатие прекращает прием и дообслуживает всех, второе - немедленный выход
4) инварианты проверяются после каждого события
